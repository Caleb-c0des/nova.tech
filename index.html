One runtime.
Every workload.

The nova engine unifies compute, storage, and inference
into a single programmable surface. Write code once — it
runs at the edge, on the GPU, or against your data, with the
same primitives.

Typed end-to-end — schema, transport, runtime

Deterministic deploys with zero-downtime rollback

Pay for milliseconds, not provisioned servers

OpenTelemetry-native observability built in

~/nova/engine.ts

import { engine } from "@nova/core";

export const handler = engine

.route("/signal")

.input(z.object({ prompt: z.string() }))

.stream( async ({ input, ai }) => {

return ai.complete({

model: "nova-1.5",

prompt: input.prompt,

});

});
